本说明列出梯度坐标系更正后哪些结果会变化。

## 规则

FSL `.bvec` 的数值以 NIfTI 图像的体素轴表示。梯度的世界方向是 `R F b`。
`R` 是列向量归一化后的图像仿射矩阵。仿射行列式为正时，`F` 翻转第一个轴。
这是 FSL 和 MRtrix 的约定。此前部分路线按另一坐标系写入或读取梯度。

## 不变的输入

- 行列式为负、各轴与坐标轴对齐的 NIfTI 图像（例如 LAS，即常见的 FSL 和 HCP
  存储方式）。UKF、原生张量拟合、独立运行的 DDSeg DTI 特征、DIPY 追踪、DKI
  和 NODDI 的结果与此前相同。转换后的 UKF 和张量头文件逐字节一致。
- 各轴对齐网格或各向同性体素上的张量拟合矩阵逐位一致。（行列式为正时梯度仍按下表变化。）
- 导入的 NRRD 中，DWIConvert 写出的 `.bvec` 已与源梯度一致时，`.bvec` 文件
  保持逐字节一致。

## 会变化的输入

| 输入 | 变化的路线 |
|---|---|
| 行列式为正（例如 RAS 存储） | UKF、原生张量、独立运行的 DDSeg DTI 特征、DIPY 追踪、DKI、NODDI |
| 斜切或轴置换的网格，行列式为负 | UKF 和独立运行的 DDSeg DTI 特征（DWIConvert 丢弃了旋转） |
| 斜切且体素各向异性的网格 | 原生张量拟合：张量方向、FA、MD 和特征值 |
| 斜切 NRRD 导入 | 按源梯度重写导入的 `.bvec` 文件 |

FA、MD 和特征值与梯度坐标系无关，只在斜切各向异性的张量拟合情形中变化。
上表每种情形中，张量方向、彩色方向图和流线都会变化。

## 缓存结果

原生 DTI、扩散头文件和配准后 DTI 缓存记录了转换、张量拟合和准备步骤的代码。
NIfTI 图像各轴与扫描仪坐标轴严格对齐（顺序不限）且行列式为负时，这些记录保持原值，
已完成的结果会被复用。其他输入更新后重新计算一次。缓存记录了原生 DTI 缓存的
后续步骤（例如配准后的 DTI 数据和微结构图）随后也会重新计算。
UKF、DIPY 追踪、DKI、NODDI 和 NRRD 导入只对上表中的输入重新计算。独立运行的
DDSeg DTI 特征文件夹没有缓存键：删除其输出文件夹中的 `DTI/` 即可重新计算。
独立运行的 DDParcel 模块在文件已存在时复用其扩散头文件和张量文件。对上表中的输入，
删除该受试者的输出文件夹，以及受试者输入文件夹 `T1w/Diffusion/` 中的
`<subject>-mask.nhdr` 文件，即可重新计算。表面重建的 `raw` 模式对每个输入都会为每个受试者
重新拟合一次张量；对不变的输入，输出与此前相同。
