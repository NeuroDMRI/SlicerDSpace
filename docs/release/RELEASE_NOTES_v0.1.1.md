# SlicerDSpace v0.1.1

**Required 3D Slicer version:** **3D Slicer 5.10.0**

## Installation

1. Download the Setup `.zip` archive for your operating system from **Assets** below:
   - **macOS (Apple Silicon `arm64`)**: `SlicerDSpaceSetup-macOS.zip`
   - **Windows (`x86_64`)**: `SlicerDSpaceSetup-Windows.zip`
   - **Linux (`x86_64`)**: `SlicerDSpaceSetup-Linux.zip`
2. Open **3D Slicer 5.10.0**, go to **Extensions Manager -> Install Extension from File...**, select the downloaded `.zip` file, and restart Slicer when prompted.
3. After restarting, the **SlicerDSpace Setup** window opens automatically. Review your options (or optional WMA atlases) and click **Start Install**. Once installation finishes, restart Slicer and open **Modules -> Diffusion -> SlicerDSpace**.

> Alternatively, you can customize options before downloading on the [SlicerDSpace website](https://neurodmri.github.io/SlicerDSpace/#start).
